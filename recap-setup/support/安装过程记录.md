## 执行安装

```bash
cd ~/RLinf-recap
bash recap-setup/support/install.sh --dry-run
bash recap-setup/support/install.sh
```

封装脚本读取 `.github/workflows/embodied-e2e-tests.yml` 中的 NVIDIA OpenPI job，通过 `.agents/skills/test-install/driver.py` 调用官方安装器。它使用以下命令，并将缓存、LIBERO 配置和下载资源放进本仓库：

```bash
bash requirements/install.sh embodied --model openpi --env maniskill_libero \
  --no-root --install-rlinf --venv /home/suchenyu/RLinf-recap/.venv
```

`--no-root` 复用主机已有的 CUDA 和系统工具链；`--install-rlinf` 将当前 checkout 以 editable 模式安装。`UV_LINK_MODE=copy` 让安装器对 Transformers 的修改留在本环境内。

安装器会按 NVIDIA 驱动选择 PyTorch CUDA wheel。CUDA toolkit 与 wheel 自带的 CUDA runtime 可以版本不同；FlashAttention 必须匹配当前 Torch ABI，官方脚本负责选择。

本机已缓存匹配 Torch 2.11 / CUDA 13 的官方 FlashAttention wheel（`support/wheels/`）。封装脚本检测到该文件时使用 `--no-flash-attn` 跳过网络下载，在官方安装器完成后检查 Torch ABI，再安装本地 wheel；该 wheel 与官方安装器的 RLinf release 地址一致。下载时已通过 ZIP 校验。

重新安装时可直接重跑封装脚本；核对日志与 [安装状态](安装状态.md)。运行环境验证：

```bash
source ~/RLinf-recap/recap-setup/activate.sh
python recap-setup/support/verify.py
```

GPU 验证应在可访问 NVIDIA 设备的主机终端执行。受限沙箱可能无法访问 GPU；以主机端验证记录为准。


## 从 GitHub 重新克隆

```bash
git clone --branch recap https://github.com/scy-v/RLinf.git ~/RLinf-recap
cd ~/RLinf-recap
bash requirements/install.sh embodied --model openpi --env maniskill_libero \
  --no-root --install-rlinf --venv .venv
```

`recap` 初始提交与 `main` 相同；当前分支已包含 `recap-setup/`。从 fork 准备好本地仓库后，按 [安装命令](../安装命令.md) 使用封装脚本安装。以上保留首次安装时的底层命令供参考。

官方说明见 [RECAP 安装与四阶段流程](../../docs/source-en/rst_source/examples/embodied/recap.rst)。
