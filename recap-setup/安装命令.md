# RECAP 环境安装命令

在已有 `~/RLinf-recap` 仓库上安装独立 `.venv`，并检查 RECAP、UR 推理与 rollout 数采依赖。主机需已有 NVIDIA 驱动、CUDA 12.8 和系统工具链。

## 1. 安装并激活

```bash
cd ~/RLinf-recap
bash recap-setup/support/install.sh
source recap-setup/activate.sh
```

安装器复用仓库依赖流程，补充 UR 依赖和带 GUI 的 OpenCV；重装也使用此入口。模型与数据按[训练命令](训练命令.md)准备。

## 2. 检查环境

```bash
python recap-setup/support/verify.py
```

在可访问 GPU 的终端运行。检查依赖、GPU 运算、FlashAttention 前向与反向、tokenizer 和 RECAP 四阶段配置；配置可加载不代表完整训练已通过。历史版本与声明冲突见[安装状态](support/安装状态.md)，该记录日期为 2026-10-23。

## 3. 修复 UR 依赖与相机显示

```bash
bash recap-setup/support/install-ur-runtime.sh
bash evaluations/realworld/run_ur5e_vla_precision.sh --check
```

相机预览报 `cvShowImage` 或 `GUI: NONE` 时使用。检查命令不连接设备；实际预览需要桌面显示。RLinf 原生入口的实体键盘需要可读取的输入设备；可选 `keyboard_terminal_only=true` 还需要本地 X11 和 `python-xlib`。

## 4. 安装或恢复 rollout 数采依赖

```bash
bash recap-setup/support/install-ur-rollout.sh
```

复用当前 `.venv`，固定 LeRobot v3 对应提交，并安装原 UR 遥操作所需依赖；最后执行不连接设备的配置与导入检查。完整安装后也需执行此步骤，采集命令见[训练命令](训练命令.md)。

## 5. 日常激活与文件位置

```bash
source ~/RLinf-recap/recap-setup/activate.sh
```

| 内容 | 仓库内路径 |
|---|---|
| Python 环境 | `.venv/` |
| 安装、验证日志 | `recap-setup/logs/` |
| 下载缓存 | `recap-setup/uv-cache/` |
| 辅助资源和数据缓存 | `recap-setup/outputs/` |
| 环境版本记录 | `recap-setup/support/versions.json` |

底层安装过程见[辅助说明](support/安装过程记录.md)。
