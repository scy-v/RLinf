# RECAP 安装命令

以你的 fork `scy-v/RLinf` 的 `recap` 分支已准备在 `~/RLinf-recap`、且包含 `recap-setup/` 为起点，直接安装仓库内的独立 uv 环境。主机需已有 NVIDIA 驱动、CUDA 12.8 和系统工具链。

## 安装并验证

在准备运行 RECAP 的机器上，按顺序执行：

```bash
cd ~/RLinf-recap

# 安装依赖，创建或复用本仓库的 .venv
bash recap-setup/support/install.sh

# 激活环境
source recap-setup/activate.sh

# 验证依赖、GPU 和 RECAP 配置入口
python recap-setup/support/verify.py
```

安装脚本负责 OpenPI 及官方 RECAP 环境依赖。重新安装时也使用上述命令；模型权重、任务数据和 UR5e 适配按后续实验准备。

验证需在可访问 GPU 的终端运行，检查依赖导入、GPU 运算、FlashAttention 前向与反向、tokenizer，以及 RECAP 四个阶段的配置加载。

## 日常使用

每次新开终端，运行：

```bash
source ~/RLinf-recap/recap-setup/activate.sh
```

激活后按照 [训练命令](训练命令.md) 准备实验。
