```bash
cd ~/RLinf-recap
source recap-setup/activate.sh
```


## 3. 将 SFT checkpoint 转成 RECAP VLA 权重

填写 SFT checkpoint 和官方 π0.5 PyTorch 参考模型路径，依次执行两次转换。

```bash
CKPT=/path/to/checkpoints/global_step_所选步数
REFERENCE=/path/to/pi05_base_pytorch
NORM="$PWD/recap-setup/outputs/ur5e_insert_black_rack_state19/norm_stats.json"
SFT="$PWD/recap-setup/outputs/pi05_sft_openpi"
RECAP="$PWD/recap-setup/outputs/pi05_sft_recap"
ASSET_ID=scylearning/insert_black_rack_into_blue_slot_20260916_v01

python -m rlinf.utils.ckpt_convertor.openpi.convert --mode sft_to_openpi \
  --config-name pi05_ur_state --dtype fp32 \
  --ckpt "$CKPT" --input-norm-stats "$NORM" \
  --output-model "$SFT" --output-norm-stats "$SFT/$ASSET_ID/norm_stats.json"

python -m rlinf.utils.ckpt_convertor.openpi.convert --mode openpi_to_openpi_pytorch \
  --input-model "$SFT/model.safetensors" --input-norm-stats "$NORM" \
  --reference-model "$REFERENCE" \
  --output-model "$RECAP" --output-norm-stats "$RECAP/$ASSET_ID/norm_stats.json"
```

`$RECAP` 是后续 CFG 训练的 `actor.model.model_path`，不是 value model 的 checkpoint。第二次转换检查参数名称和形状，并按现有工具写为 bf16。
