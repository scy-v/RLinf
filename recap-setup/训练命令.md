# RECAP 四阶段命令

按官方 RECAP 流程依次计算 returns、训练 value model、计算 advantages、训练 CFG policy。以下记录官方命令和配置入口，供后续 UR5e 适配时使用。

## 激活环境

```bash
source ~/RLinf-recap/recap-setup/activate.sh
```

本次工作准备独立环境，不启动训练或机械臂。官方示例配置使用 LIBERO 的观测和动作定义；真机运行前需要完成 UR5e 数据和模型适配。

## 准备数据与模型

先在下表配置中填写实际路径，替换官方示例中的 `/path/to/...`。完整字段说明见 [官方 RECAP 文档](../docs/source-en/rst_source/examples/embodied/recap.rst)。

| 用途 | 配置文件（均位于 `examples/offline_rl/config/`） | 需要设置的字段 |
|---|---|---|
| Returns | `recap_compute_returns.yaml` | `data.train_data_paths`、`data.tag` |
| Value 训练 | `recap_value_model_sft.yaml` | 训练/验证数据、SigLIP2/Gemma3/tokenizer 路径、动作维度与 robot/model type、batch size |
| Advantages | `recap_compute_advantages.yaml` | 相同训练数据、value checkpoint、模型路径、标签、lookahead |
| CFG policy | `cfg_rl_openpi.yaml` | 相同训练数据、优势标签、pi0.5 PyTorch 基座、OpenPI 配置、batch size |

Value model 使用 `google/siglip2-so400m-patch14-224` 和 `google/gemma-3-270m`；CFG policy 使用 pi0.5 PyTorch 权重。依赖安装与模型下载是两个步骤，模型和任务数据由后续实验准备。

Returns 标签须在步骤 1 的 `data.tag`、步骤 2 的 `data.tag`、步骤 3 的 `advantage.returns_tag` 中相同；优势标签须在步骤 3 的 `advantage.tag` 与步骤 4 的 `data.advantage_tag` 中相同。四阶段使用相同的训练数据列表。SFT 数据应为成功轨迹，rollout 数据需包含正确的成功/失败信息。

## 1. 计算 Returns

```bash
bash examples/offline_rl/advantage_labeling/recap/process/run_compute_returns.sh \
  recap_compute_returns
```

读取 LeRobot 数据并生成 returns sidecar。先核对 `gamma`、`failure_reward`、数据类别和标签。

## 2. 训练 Value Model

```bash
bash examples/offline_rl/advantage_labeling/recap/run_value_sft.sh \
  recap_value_model_sft
```

日志和 checkpoint 位于本仓库的 `logs/value_sft/`。将产生的 value checkpoint 路径填入步骤 3 的 `advantage.value_checkpoint`。

## 3. 计算 Advantages

```bash
bash examples/offline_rl/advantage_labeling/recap/process/run_compute_advantages.sh \
  recap_compute_advantages --nproc 1
```

`--nproc 1` 指定单 GPU；多卡主机按实际资源修改。先核对 value checkpoint、`advantage_lookahead_step`、`positive_quantile` 和标签。

## 4. 训练 CFG Policy

```bash
bash examples/offline_rl/policy_optimization/cfg_rl/run_cfg_rl.sh cfg_rl_openpi
```

日志和 checkpoint 位于本仓库的 `logs/cfg_rl/`。策略必须使用与真机数据匹配的 OpenPI transforms、归一化统计、动作维度和 action horizon。

## 查看训练曲线

```bash
cd ~/RLinf-recap
.venv/bin/tensorboard --logdir logs --host 127.0.0.1 --port 6007
```

浏览器访问 `http://localhost:6007`；远程主机可通过编辑器转发该端口。

UR5e 真机配置、任务数据和执行命令在适配完成后记录到本文件。
