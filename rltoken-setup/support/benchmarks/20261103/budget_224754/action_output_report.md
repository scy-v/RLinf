# 不同训练阶段的 VLA 与 MLP 输出对比

## 统计范围与口径

- 运行：`20261103-224754-ur_rlt_stage2_ac_mlp`。固定截止 2026-11-04 00:02:16、2801 轮，包含 5496 条完整 inference 记录。
- `data.log` 每次记录同一观测下的 VLA 与 Actor 输出，发生在路由选择控制器之前。因此未进入关键阶段时也记录 MLP 输出；人工干预、停止保持、控制坐标变换等发生在后面，不能把输出日志当作最终执行动作。
- VLA 输出 20 步，Actor 输出 10 步，只对齐 VLA 前 10 步。按 `policy_version // 5` 分训练阶段，而不是用日志读取时的最新 learner 步数。
- 主要表格只选关键阶段内部；用主日志按键和 episode 结束的秒级时间戳确定范围，两端各留 1 秒余量。共 2426 个 chunk；另有 2123 个非关键阶段内部记录、947 个边界／等待记录。最初 version=0 的未训练 Actor 不纳入表格。
- 平移单位为米，action_scale=1，按 mm 展示；旋转按弧度转度。动作是 TCP 坐标系中的增量指令，不是世界坐标下真实轨迹误差。
- 在线输出含 fixed_std=0.002 的 tanh 前采样噪声；rollout 不启用训练 BC 使用的 reference dropout。

- 中段差异略缩小，之后扩大，但没有一路增大到失控。各阶段观测分布不同，不能只用此表推断模型参数变化。
- 后四阶段 VLA 平移指令平均模长约 7.77～8.08 mm，MLP 约 9.06～9.97 mm。MLP 并非原样复制 VLA，指令幅度通常更大，但不能据此认定实际运动更快或更好。
- 旋转差异中，后四阶段 roll/pitch 逐轴 RMS 约 0.24～0.38°，yaw RMS 约 0.64～0.71°。yaw 的平均有符号偏差逐渐接近零，但逐步差异仍存在；均值接近零不等于相同。
- 夹爪按真实执行阈值 0.5 比较，后四阶段判断不一致约 0.86%～1.18%。这些是两套模型建议的差异，不能直接算实际误开夹爪次数。
- 同一 chunk 内相邻平移指令变化，VLA 平均约 1.15～1.35 mm，带噪 MLP 约 6.4～6.7 mm。它衡量指令序列变化，不是机械臂实际速度／加速度或抖动。

## 固定输入、去掉探索噪声的对照

从 267 checkpoint 选 96 条早期在线样本，从 2762 checkpoint 选 96 条之后新增的在线样本，均无人工覆盖且非终止，共 192 个唯一输入。对所有 checkpoint 固定同一批 z_rl、proprio、参考动作，CPU float32、eval 确定性推理。该样本选择与在线全量日志不同，绝对均值不可直接互相比较。

| checkpoint | 确定性 MLP 与 VLA 平均 XYZ 差 / mm | 确定性 MLP 相邻指令变化 / mm |
|---|---:|---:|
| 267 | 8.01 | 5.74 |
| 1276 | 7.22 | 6.22 |
| 1520 | 7.91 | 5.85 |
| 2003 | 8.28 | 7.16 |
| 2762 | 8.84 | 7.01 |

同一批参考 VLA 的相邻指令变化为 1.40 mm。这批输入上，不加探索噪声时 MLP 仍比参考动作有更大的 chunk 内变化，因此差异不全来自噪声。是否对应实际轨迹变差，还受人工接管、PD 跟踪和接触约束影响。

- **参数变化确实影响输出**：固定输入，1520→2003 的 MLP 输出平均 XYZ 向量差为 6.68 mm，逐轴 RMS 为 4.40／3.83／4.23 mm；2003→2762 平均向量差为 6.46 mm。此前“actor 对 Q 均值变化贡献小”，不代表动作变化小。
- **方向性变化**：固定输入时，1520→2003 的平均指令变化为 (+3.23, -2.07, -2.41) mm；2003→2762 为 (-2.80, +0.09, -1.41) mm。这是 TCP 动作坐标，不能不结合姿态直接说成世界坐标的左右或上下。
- **噪声贡献**：同一输入做 4 组配对随机种子采样，采样输出相对确定性输出的 XYZ 逐轴 RMS 约为 1.99／1.99／2.02 mm。不能直接从平均向量差中减去 2 mm；需分别看模型输出差与采样波动。
- **非单调关系**：Q 回升期间，固定输入上 MLP 与 VLA 差异从 7.22 增至 7.91 mm；Q 再下降期间继续增至 8.28 mm。说明 Q 上升／下降与“更接近 VLA”不是一一对应关系。

## 判断

MLP 已明显改变 VLA 的动作幅度、方向和 chunk 内序列；探索噪声只能解释其中一部分。同一输入在不同 checkpoint 下仍有数毫米级指令变化，而 Q 均值对 actor 替换变化较小，说明不能用 Q 接近或 BC 小来代替动作稳定性判断。上述结果定位了输出差异，未证明哪一组动作更有利于插入，也未证明轨迹误差或训练发散；更接近 VLA 也不必然更优。

本次只读取日志并在 CPU 执行无梯度推理；未修改训练参数、运行网络更新或连接机器人。
