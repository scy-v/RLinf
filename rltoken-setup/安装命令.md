# UR 环境安装

辅助安装脚本、环境记录和检查工具位于 `support/`。[英文说明](support/INSTALL_COMMANDS.en.md)。

## 当前仓库直接安装

UR 入口已添加，直接安装，不需要先装 Franka。

```bash
cd ~/RLinf
bash requirements/install.sh embodied --model openpi --env ur \
  --venv .venv --no-root --install-rlinf
```

也可使用封装脚本安装并修复 OpenCV 显示支持：

```bash
bash rltoken-setup/support/install.sh
```

## 从零 clone

`--env ur` 保存在 fork 的 `rlt` 分支。重新安装时直接克隆该分支。

```bash
git clone --depth 1 --branch rlt https://github.com/scy-v/RLinf.git ~/RLinf
cd ~/RLinf

curl -LsSf https://astral.sh/uv/install.sh | sh
export PATH="$HOME/.local/bin:$PATH"

bash requirements/install.sh embodied --model openpi --env ur \
  --venv .venv --no-root --install-rlinf
```

## OpenCV 显示支持

OpenPI 安装后执行：

```bash
source ~/RLinf/.venv/bin/activate
uv pip uninstall opencv-python opencv-python-headless
uv pip install --no-deps opencv-python==4.11.0.86
```

## 日常使用

```bash
source ~/RLinf/.venv/bin/activate
```

UR 的 LeRobot 读取器固定为提交 `d6ea3bbce0fc8c75138f02639ac4ceaf12a67829`，与你的 OpenPI 环境相同，支持本数据集的 v3.0 格式。安装器复用 RLinf 已有的 Torch/Datasets 依赖栈。

UR 依赖文件：`requirements/embodied/envs/ur.txt`，包括 RTDE、DH 夹爪和空间鼠标。
